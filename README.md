# WhacMoleGame

**WhacMoleGame** — это веб-игра, разработанная на платформе .NET. Игроки могут наслаждаться классической механикой "Whac-A-Mole" через браузер. Проект демонстрирует возможности современных веб-технологий в игровой индустрии.

## 🚀 Особенности

- Веб-игра на основе .NET.
- Реализация с использованием PostgreSQL для управления базой данных.
- Простая и увлекательная игровая механика.

## 🛠️ Требования

- **.NET SDK**: версия 8.0 или выше.
- **База данных**: PostgreSQL.
- **Браузер**: Любой современный браузер.

## 📥 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/PANiXiDA/WhacMoleGame.git
   ```

2. **Настройте базу данных PostgreSQL:**
   - Убедитесь, что PostgreSQL установлен и запущен.
   - Создайте базу данных, например, `whacmolegame`.

3. **Примените миграции:**
   Выполните следующую команду, чтобы создать таблицы в базе данных:
   ```bash
   dotnet ef database update Initial --context DefaultDbContext --project Dal/Dal.DbModels/Dal.DbModels.csproj -s PL.MVC/PL.MVC.csproj
   ```

4. **Запустите проект:**
   Перейдите в директорию `PL.MVC` и выполните:
   ```bash
   dotnet run
   ```
   Приложение будет доступно по адресу [http://localhost:5296](https://localhost:7075).

## 🧩 Как играть

1. Перейдите на главную страницу игры в браузере.
2. Зарегистрируйтесь прежде чем начать игру.
3. Ловите кротов, кликая на них, чтобы заработать очки.
